# Super Lotto Helper（大乐透统计与记录）

个人用的超级大乐透桌面工具：看开奖、标号、缩号、每周推测落库。仅供统计与记录，不构成投注建议。

## 运行

```powershell
python -m pip install -r requirements.txt
python main.py
```

首次启动会导入 `assets/dlt_history.csv`。之后点「刷新开奖」增量抓取新期。数据写在程序旁的 `data/dlt.db`，不删软件就不会丢。

打包 EXE：

```powershell
python package.py
```

生成文件在 `dist/大乐透统计与记录.exe`，请与同目录 `data` 文件夹一起拷贝。

## 功能

1. 开奖列表与号值统计（次数、频率、遗漏、近 30/100 期、EWMA）
2. 刷新抓取新一期（体彩接口优先，失败回退 500.com）
3. 前区 / 后区号码球标注：默认、重点关注、排除
4. 悬停查看奇偶与三区
5. 232 三区复式池与单式形态（221 / 212 / 122 / 131 / 113）
6. 奇偶约束、冷热 / 遗漏 / EWMA / 综合打分
7. 金胆 / 银胆 / 铜胆，生成后画在号码球上
8. 和值均值、常用区间，可约束推荐注落在均值 ±σ
9. 推测日志本地保存、检索、删除、开奖对照
10. 备份导入导出；数据目录跟随程序
